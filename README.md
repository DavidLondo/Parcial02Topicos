# Repositorio del parcial 02 de Tópicos Especiales de Ingeniería de Software

En este repositorio está el código de la parte práctica del segundo parcial usando Flask.

Para instalar flask ejecuta

```bash
pip install flask
```

Y para ejecutar el programa

```python
python app.py
```

Ahora solo tendrás que buscar esto en un navegador:

http://127.0.0.1:5000/numero

Siendo "numero" el número al que quieras calcularle el factorial
